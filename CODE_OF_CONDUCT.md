# Code of conduct

Be respectful and constructive. In issues, pull requests and discussions:

- No harassment, discrimination, personal attacks or doxxing.
- No spam, advertising or off-topic promotion.
- Assume good faith, keep feedback about the work, not the person.

The maintainer may edit, hide or delete comments, and lock or close threads,
and may block users who violate these rules. Report problems through a
private security advisory or the maintainer's GitHub profile.
